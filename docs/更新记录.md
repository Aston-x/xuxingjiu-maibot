## 背景：v1.2 → MaiBot 版的重写链

| 阶段 | 变化 | 原因 |
|---|---|---|
| v1.2 | 自研单体 `qqbot/` + NapCat 控制端 | — |
| 控制端 | NapCat → **SnowLuma**（只 hook，QQ 完整 UI 照跑） | NapCat 替换 QQ 入口 → 账号**容易被封**；SnowLuma 不替换入口，桌面 QQ 保持正常 |
| 大脑 | 自研单体 → **MaiBot** | SnowLuma 的 hook 是**闭源原生二进制**，改不了 → 大脑也必须是自己能掌控的开源件；而 OneBot v11 让协议端可随时再换 |
| 插件 | 手写日记插件 → **官方 better-diary** | 没必要自己造；市场 400+ 插件 |
| 记忆 | 自写 JSON → **A_Memorix** | 双层检索 + 会话作用域 + 摘要化 + 衰减策略 |
| 语音 | 无 → **GPT-SoVITS**（含自训角色音色） | 会说话、会唱歌；音色可自己训 |

旧仓库用归档 tag `archive-开源v1.3支线-20260929-已被桌宠重构线取代` 标记停更。
